导入教学视频

支持“音符从上往下掉”的钢琴教学视频（mp4 / webm），也可以直接导入 MIDI 文件。

🎵 歌曲 → 钢琴版

放一首歌进来（mp3 / m4a / wav，或带声音的视频），自动扒出音符、编成钢琴版来练。在本机算，歌不会上传。

对齐键盘

已自动找键盘。检查：蓝线在键盘上沿，黄线是检测线（在键盘上方一点点，上面那条淡黄线用来排除视频里静止的标题和水印），每个键上的小点要对准琴键，画面上的 C 标签和视频里的一致。点亮的小点 = 这一帧识别到的音符。
